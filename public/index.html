关于

数据仅保存在本机；服务只监听 127.0.0.1。加密：scrypt(N=2¹⁷) → HKDF-SHA256 → AES-256-GCM， 文件级 HMAC-SHA256 封印。Qsecret 为本地个人工具，未经过第三方安全审计。

使用手册

1. 快速开始

  1. 第一次打开：页面会要求设置主密码，输入两次，至少 12 位。建议用 4 个以上互不相关的单词组成，不要和任何网站密码相同。
  2. 以后每次使用：输入主密码，点「解锁」。按钮会显示"正在派生密钥…"约 1 秒——这是 scrypt 故意设计得慢，用来拖慢暴力破解。
  3. 添加第一条：点右上角「新建条目」，填写后保存。
主密码不会保存，也无法找回。 忘记主密码等于永久失去全部数据，没有任何后门。设置后请立刻做一次加密备份（见第 7 节）。

全部数据以密文保存在本机应用目录的 data/vault.qvault，不上传、不同步、无遥测。

2. 管理条目

新建右上角「新建条目」，或空列表里的「新建一条」。标题必填；分类有登录账号 / 银行卡 / 服务器·密钥 / 安全笔记 / 其他；标签用逗号分隔。
查看点左侧条目，右侧显示详情。密码默认是圆点，点眼睛图标才显示明文，30 秒后自动隐藏。
复制账号、密码、网址右侧有复制按钮。复制后 45 秒尝试清空剪贴板（仅当内容没被你替换时）。需要浏览器授予剪贴板权限。
编辑详情右上角「编辑」。打开时会自动读取并回填原密码；密码框留空保存会把该条密码清空。
删除详情右上角「删除」，需确认。删除后不可撤销，只能用之前的备份文件恢复。

3. 密码生成器

  • 入口：顶栏「生成密码」，或条目编辑框里密码右侧的「生成」。
  • 长度 8–64 位，可勾选大写、小写、数字、符号；默认排除易混淆的 0 O 1 l I。
  • 「使用此密码」：从条目里打开 → 直接填入密码框；从顶栏打开 → 复制到剪贴板。
  • 随机数来自操作系统加密随机源，在本机生成，不经过网络。

4. 查找与整理

  • 搜索：匹配标题、账号、网址、备注、标签。快捷键 ⌘K（Windows 为 Ctrl+K）跳到搜索框，Esc 清空。
  • 分类：左侧分类栏带数量，点击筛选。
  • 标签：点标签筛选，再点一次取消；点分类会清除标签筛选。
  • 搜索和筛选都在浏览器内存里完成，不会向服务发送任何请求。

5. 安全概览

  • 弱密码：强度评分低于 60 的条目数，列表里用黄色圆点标出。
  • 重复使用：与其他条目密码相同的条目数，列表里用红色圆点标出。一个网站泄露会连带其他网站，建议逐个改成独立密码。
  • 健康度：没有弱密码、没有重复的条目占比。

6. 锁定与会话

手动锁定右上角「锁定」，或 ⌘⇧L（Ctrl+Shift+L）。密钥立即从内存抹除。
空闲锁定默认 5 分钟无操作自动锁定，可在设置中改为 1 / 5 / 15 / 30 / 60 分钟。左下角显示倒计时。
绝对超时解锁满 8 小时后必须重新输入主密码，无论是否在操作。
输错密码第 5 次失败起锁定 60 秒，之后每次翻倍，最长 1 小时。计数保存在磁盘上，重启服务也绕不过。
服务在后台运行 ≠ 保险库已解锁。电脑重启或服务自动启动后，仍然需要输入主密码才能看到任何条目。

7. 主密码、备份与恢复

  • 修改主密码：设置 → 输入当前主密码和新主密码 → 确认。全部条目会用新密钥重新加密，旧密码立即失效。改完请重新下载一份备份。
  • 备份：设置 → 「下载加密备份」，得到 qsecret-backup-日期.qvault。文件本身是密文，但请和主密码分开保存（例如备份放网盘，主密码记在纸上）。
  • 恢复：设置 → 填写备份文件对应的主密码 → 选择 .qvault 文件 → 确认。会覆盖当前全部数据，系统会保留一份覆盖前的 .bak。
  • 迁移电脑：把整个应用目录拷到新机器，或在新机器建库后用备份恢复。
  • 忘记主密码：没有找回方式，只能删除 data/vault.qvault 后重新创建（旧数据放弃）。

8. 后台服务（开机自启）

安装双击应用目录里的 service/install.command。之后每次登录系统自动在后台启动，意外退出会自动拉起。
卸载双击 service/uninstall.command。只移除自启项和后台进程，不会删除你的数据。
访问浏览器打开 http://127.0.0.1:7878，建议加到书签。服务只监听本机回环地址，局域网内其他设备无法访问。
日志~/Library/Logs/qsecret.log（错误在同目录 qsecret.error.log）。日志不含密码和条目内容。
手动启动没装服务时，双击 start.command，关闭窗口即停止。若服务已在运行，双击它只会打开浏览器。
服务会固定使用安装时找到的 Node.js 路径。如果以后卸载或升级了那个 Node 版本，请重新运行一次 service/install.command。

10. 常见问题

页面打不开 / 提示"无法连接本地服务"
服务没在运行。装过后台服务的，在终端执行 launchctl list | grep qsecret 查看；没有的话双击 start.command。
提示"尝试次数过多，请等待 N 秒"
主密码连续输错触发了保护，等待倒计时结束后再试。等待时间会随失败次数变长。
提示"文件完整性校验失败"
保险库文件被改动或损坏，出于安全已拒绝打开。把 data/vault.qvault.bak 改回 vault.qvault 试试，或用备份文件恢复。
点复制提示"浏览器拒绝了剪贴板访问"
在浏览器地址栏的站点设置里允许剪贴板权限，或点眼睛显示后手动选择复制。
能在手机或多台电脑上用吗？
不提供云同步。其他设备可通过手动拷贝备份文件 + 恢复的方式使用，注意后恢复的会覆盖当前数据。
它能防什么、不能防什么？
能防文件被拷走、被篡改、恶意网页跨站调用。防不了已经控制这台电脑的木马、键盘记录器和恶意浏览器扩展——任何本机密码管理器都一样。
